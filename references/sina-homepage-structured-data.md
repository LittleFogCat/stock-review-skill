# Sina 首页结构化板块数据采集（2026-08-06 验证）

## 发现

Sina 财经首页 `https://finance.sina.com.cn/stock/` 通过 `browser_console(expression="document.body.innerText")` 提取的全文中，包含**结构化的 TOP10 板块排名数据**，远比此前文档记载的「从标题关键词提取板块线索」更精确。

## 可提取的结构化数据


### 个股涨幅/换手率 TOP10

同样格式，包含个股名称、最新价、涨幅、换手率。

### 热门股票 / 资金流入排行

包含个股名称、最新价、涨跌幅等。

## 采集方法

```javascript
// browser_console 一步提取全部结构化数据
document.body.innerText
```

返回的纯文本中，搜索 `排名\t名称\t涨幅` 即可定位板块表格区域。用正则或字符串分割提取。

## 优势

1. **精确涨跌幅**：板块涨幅是 Sina 服务端计算的精确值（如「煤炭行业 4.44%」），非代表性个股估算
2. **领涨股+涨幅**：每个板块附带领涨股名称及其精确涨幅（如「昊华能源 10.04%」）
3. **单次请求**：一个 `browser_navigate` + 一个 `browser_console` 即可获取全部板块/概念/个股排名
4. **SSR 渲染**：Sina 首页是服务端渲染，数据直接在 HTML 中，无需等待 JS 加载

## 与其他数据源的对比

| 数据源 | 板块涨幅精确度 | 领涨股 | 单次请求 | 可靠性 |
|--------|--------------|--------|---------|--------|
| **Sina 首页 innerText** | ✅ 精确 | ✅ 附带 | ✅ | ✅ 稳定 |
| Sina /tob/ 收评文章 | ❌ 文字描述 | ✅ 列出 | ✅ | ✅ 稳定 |
| 东财 push2 API | ✅ 精确 | ❌ 需另查 | ❌ 已封 | ❌ 不可用 |
| 腾讯 pt 板块代码 | ⚠️ 部分返回 | ❌ | ⚠️ 多次 | ⚠️ 不全 |

## 推荐采集流程（2026-08-06 验证）

1. `browser_navigate` 到 `https://finance.sina.com.cn/stock/`
2. `browser_console(expression="document.body.innerText")` 提取全文
3. 从全文中搜索 `行业涨幅` / `概念涨幅` 定位板块表格
4. 用正则提取 TOP5/TOP10 板块名+涨幅+领涨股+涨幅
5. 同时提取 `<a>` 链接列表（`browser_console` JSON.stringify）找到 /tob/ 和 /cpbd/ 文章 URL
6. 逐篇 `browser_navigate` + `browser_console` 提取收评/操盘必读全文

**单次首页访问即可获得**：板块排名 + 概念排名 + 个股排名 + 指数行情条 + 收评/操盘必读文章链接。是当日复盘数据采集的最高效入口。
