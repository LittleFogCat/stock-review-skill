# 美股联邦节假日休市陷阱（2026-09-08 实测）

## 场景

2026-09-08（周二）早盘快报，前一交易日是 9/7（周一）。但 9/7 是**美国劳动节（Labor Day）**，美股休市。腾讯 API `qt.gtimg.cn/q=usDJI,usIXIC,usINX` 返回的时间戳索引 [30] 是 **2026-09-04 16:33:30**（上周五收盘），而非 9/7。此时「隔夜美股」= **9/4 周五**，不是 9/7 周一。

## 与「周末」陷阱的区别

| 维度 | 周末休市 | 联邦节假日休市 |
|------|---------|--------------|
| 触发条件 | 固定：周一早盘 | 不固定：节假日可落任意工作日 |
| 直觉失效点 | 周日无交易 | 「周一美股照常开盘」的直觉失效 |
| 例子 | 周六/周日 | 劳动节（9月首个周一）、感恩节（11月周四）、圣诞、独立日（7/4）、马丁·路德·金日等 |

**核心规则**：A 股周一照常开盘，但美股「隔夜」基准可能是更早的周五甚至周四。**绝不能假设美股每个工作日都有收盘数据。**

## 正确处理

1. **早盘 08:00 采集美股时，必须检查腾讯 API 返回的时间戳字段 [30]**（格式 `YYYY-MM-DD HH:MM:SS`，美东时间），确认其指向哪个交易日。
2. 若时间戳不是"前一交易日"，则「隔夜美股」写**实际时间戳对应的交易日**，并在报告中显式标注（如「受美国劳动节假期影响，周一（9/7）美股休市，隔夜美股基准为上周五（9/4）收盘」）。
3. **美股期货可作补充**：休市当日的盘前报道（Sina 外盘头条 / 操盘必读「环球市场」节）会给出美股指数期货涨跌（如 2026-09-08 操盘必读记载：道指期货 -0.62%、标普500期货 -0.17%、纳指100期货 +0.13%）——这是"节后首个交易日"的市场预期，可写入报告，但**明确标注为期货而非收盘价**。
4. **A 股个股验证不受美股节假日影响**：`qt.gtimg.cn/q=sh/sz+code` 仍按前一 A 股交易日（如 9/7）返回，时间戳 [30] 指向 9/7 16:14 等。美股 `usXXX` 休市只影响美股代码，不影响 A 股 `sh/sz` 代码。

## 2026-09-08 实测

- 美股期货作为"节后首个交易日"预期写入报告。
- A 股 9/7 复盘（创业板指 +3.41%、CPO/算力硬件爆发）正常作为"昨日 A 股回顾"。
