# 风险信号实战案例库

## 2026-07-28：韩国KOSPI暴跌引发全球科技股去杠杆（R1-4a + R1-4b）

**触发条件**：
- R1-4a：韩国KOSPI单日跌10.84%（≥8%阈值），虽未触发熔断但属极端跌幅
- R1-4b：韩国KOSPI 7月累跌近30%（≥20%阈值），伴随大规模杠杆爆仓
- 120万+杠杆散户账户触及保证金追缴线，32-36万账户被全额强平

**传导路径**：
1. 韩国杠杆爆仓 → 全球科技股恐慌情绪传导
2. SK海力士ADR跌破发行价 → 半导体板块全球性抛售
3. A股CPO/半导体板块遭遇外资+内资合力抛售
4. 新易盛-17.13%、中际旭创-15.69%、源杰科技-16.77%、普冉股份-16.62%
5. 创业板指跌7.35%、科创50跌6.33%

**风险等级判定**：
- 美股三大指数未达R1-B-6阈值（道指+0.51%、纳指-0.18%、标普+0.02%）→ 未触发R1-B-6
- 但韩国市场暴跌触发R1-4a + R1-4b → R1级别
- A股内部暴跌（创业板-7.35%）本身不触发R1（R1针对全球系统性风险），但叠加外围暴跌构成R1

**实际输出**：
- 输出R1风险提示，措辞"全球科技股去杠杆同步进行，韩国杠杆爆仓传导恐慌情绪"
- 操作建议："科技板块去杠杆可能导致反复震荡，不建议抄底AI硬件/半导体。银行/消费有对冲价值"
- 次日观察点：关注韩国政策干预、美股科技财报、创业板超跌后能否企稳

**降级判断**：
- 若次日韩国市场继续暴跌但无新升级信号（如韩国央行干预后市场回稳），可降级为R2
- 若出现新升级（如韩国宣布全面禁止杠杆交易、或美股科技股暴跌≥5%），维持R1

**教训**：
- 原R1-B-4仅覆盖"触发熔断"，漏掉了"跌幅≥8%但未熔断"的极端场景
- 韩国KOSPI跌10.84%虽未触发熔断机制，但恐慌传导效应等同甚至超过一般熔断
- 月度累跌≥20%是持续性系统性风险信号，不能因为"不是今天的新闻"而忽略
- ⚠️ **SIDECAR ≠ 熔断（2026-08-06 实测）**：新浪文章标题「韩国综指大跌5%触发熔断」实际触发的是 **SIDECAR**（暂停程序化卖盘），并非全面熔断（停盘）。KOSPI 当日收跌 4.59%，未达 R1-B-4a 的 8% 阈值，也未触发全面熔断。Agent 看到标题中「熔断」二字时，**必须读正文确认实际机制类型**：SIDECAR = 暂停程式卖盘（交易继续）；Circuit Breaker/熔断 = 全市场暂停交易。SIDECAR 单独不触发 R1-B-4，需结合实际跌幅判断是否触发 R1-B-4a（≥8%）或 R1-B-4b（月度≥20%）。

## 2026-08-06：韩国KOSPI触发SIDECAR但未达R1阈值（SIDECAR vs 熔断区分实战）

**场景**：8/6 早盘，韩国KOSPI跌超5%触发SIDECAR机制（暂停程序化卖盘），SK海力士跌10.3%、三星电子跌6.3%。新浪文章标题使用「触发熔断」措辞。A股三大指数低开后震荡回升，沪指收涨0.57%。

**风险等级判定**：
- KOSPI 收跌 4.59% -> 未达 R1-B-4a（≥8%）阈值
- KOSPI 触发的是 SIDECAR（暂停程式卖盘），非全面熔断 -> 不触发 R1-B-4
- 无其他 R1 触发条件满足（美股道指+0.49%、VIX未跳涨30%+、原油-0.91%）
- **综合判定：R0（常态）**，仅在复盘中提示外部波动，不输出 R1/R2 风险提示块

**关键区分**：
- SIDECAR：韩国交易所暂停程序化卖盘5分钟，人工交易继续。是「减速带」不是「停牌」
- 熔断（Circuit Breaker）：全市场暂停交易。韩国KOSPI的熔断阈值为-8%/-15%/-20%
- 新闻标题常将SIDECAR笼统称为「熔断」，agent 必须读正文确认

**实际输出**：未输出R1/R2风险提示块，仅在复盘开头以普通提示语提及「韩国KOSPI跌4.59%触发SIDECAR，外部科技股波动加剧，但A股展现韧性」

**教训**：
- 新闻标题中的「熔断」不可直接采信为R1-B-4触发依据
- SIDECAR是韩国市场常规波动控制机制，2026年7-8月已多次触发，不构成系统性风险信号
- 判断R1-B-4时以**实际跌幅数字**为准（≥8%），不以机制名称为准

## 2026-07-30：R1持续第3日 + 多重升级信号维持完整R1（持续性R1判定实战）

**场景**：7/28 韩股暴跌触发R1，7/29 R1持续第2日，7/30 进入第3日。按「持续性R1降级处理」原则，第4日起应降级为R2，但7/30出现了多重新升级信号，维持完整R1。

**7/30 新增升级信号**（满足"重大升级"判定标准）：
1. **美联储3名委员反对主张加息**（R1-C-9 美联储官员公开反转立场）——自2016年以来首次3张方向一致反对票，巴克莱定性为"鹰派的按兵不动"，市场押注9月加息
2. **中东冲突重大升级**（R1-A-1 实际军事冲突 + R1-A-5 原油单日涨≥8%接近触发）——特朗普称伊朗向中东美军发射导弹要"狠狠打击"，WTI+6.56%/布伦特+7.91%（布伦特接近8%阈值但未达到，WTI未达到）
3. **美股道指-2.19%**（未达R1-B-6的≥3%阈值，但创2025年4月以来最大单日跌幅，市场恐慌信号）
4. **费城半导体-5.33%连续5日下跌**（科技股持续去杠杆未结束）

**关键判定逻辑**：
- 布伦特+7.91%接近但未达到R1-B-8的8%阈值——**不单独触发R1-8**，但作为"重大升级信号"之一纳入综合判断
- 美联储3票反对是**新出现的**升级信号（7/28-29不存在），满足"重新升级为完整R1"的条件
- 中东冲突从"每晚空袭"（例行持续）升级为"伊朗向美军发射导弹+特朗普威胁狠狠打击"（重大升级），满足升级标准

**实际输出**：
- 完整R1模板，列出5条具体风险事件
- 操作建议："今日不建议新增科技仓位，关注韩股企稳信号和美联储后续表态。存储芯片板块短期规避。油气板块可关注但需注意追高风险"
- 关注个股表格列出9只但全部标注模型评分均为负值，声明"不建议作为买入推荐"

**教训**：
- 持续性R1降级不是自动的——第3日如果出现新的重大升级信号，仍应维持完整R1
- "重大升级" vs "例行持续"的判断标准需具体化：美联储3票反对=重大升级（新事件）；韩股继续跌=例行持续（同一事件延续）
- 原油涨7.91%接近8%阈值但未触发--在综合判断中可作为"接近触发"的辅助信号，但不单独构成R1-8触发

## 2026-08-03：R1降级为R2 + 油价暴跌引发板块方向切换

**场景**：7/28 韩股暴跌触发R1，7/30 维持R1（中东升级+美联储鹰派），7/31 A股超跌反弹（创业板+3.06%），8/3 周一早盘快报。中东局势出现缓和信号：特朗普称同意取消对伊朗打击，WTI原油周一开盘暴跌6.22%至79.40美元/桶。但伊朗法尔斯通讯社否认海峡协议，不确定性仍存。

**风险等级判定**：
- 中东冲突从「伊朗向美军发射导弹+特朗普威胁打击」→「特朗普称同意取消攻击+双方谈判中」= 重大缓和信号
- 按「持续性R1降级处理」原则，冲突出现实质性缓和 → 降级为R2
- 但伊朗否认协议 = 不确定性仍在 → 不能直接降到R0
- 7月A股极端调整（创业板月跌23%、科创50月跌25.9%）→ 修复尚不稳固
- **综合判定：R2**

**板块方向切换（核心新知）**：
R1降级为R2时，油价暴跌6%+产生方向性板块切换：

| 方向 | 利空板块 | 利好板块 |
|------|----------|----------|
| 油价暴跌6.22% | 石化能源（中国石化-0.19%、陕西煤业+0.24%相对承压） | 航空物流（南方航空+1.35%、中国国航+1.30%） |
| 黄金+0.75% | — | 黄金股（避险需求仍在但减弱） |

**处理要点**：
1. R1降级为R2时，不能只降低风险等级措辞，还要**重新审视板块推荐方向**——油价暴跌时航空取代能源成为受益板块
2. 同时关注伊朗方面否认消息，不确定性仍在
3. 关注板块表格中应同时反映「缓和受益方向」（航空）和「不确定性对冲方向」（黄金），让主人自行判断

**实际输出**：
- R2风险提示，措辞「中东局势出现缓和迹象但伊朗否认协议，不确定性仍存」
- 操作建议：可谨慎参与，仓位上限50%，设止损线-3%
- 关注板块新增「民航/航空」（原油暴跌利好），保留「核电」「AI应用」等政策催化方向
- 关注个股新增南方航空(600029)，同时保留中国核电/中国核建（国常会核准1700亿核电项目）

**教训**：
- R1降级不只是「降低措辞强度」，还要识别降级 catalyst 带来的**新板块方向**——这次是油价暴跌→航空受益
- 「持续性R1降级」章节提到「重大升级信号」时重新升级R1，但没提到「重大缓和信号」时的板块切换——实战中这是更常见的场景
- 伊朗否认海峡协议说明「缓和」也可能反转——在关注个股中同时保留航空（缓和受益）和核电（无关中东的政策催化）作为分散
